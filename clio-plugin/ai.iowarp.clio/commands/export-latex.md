## Procedure

The manuscript already is LaTeX (`project://paper/{artifact}`), so on CLIO this action builds it rather than converting it.

1. Confirm the venue template the paper was started from (the latex plugin's `start-a-paper` skill) and the entry file, normally `paper/main.tex`.
2. Check that every `\cite` key resolves in the bibliography; run the bundled `bib-index` (below) to list its keys.
3. Build with `latex_build`, passing the entry file and the venue. Report its status, page count, venue checks and every problem by file and line; fix only what the author approves.
4. Record the build in a validation record with `wtfp_record`. The PDF is the deliverable; do not copy the source into `deliverables/`.
